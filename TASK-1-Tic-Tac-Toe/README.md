# 🎮 Tic-Tac-Toe Game

## 📌 Description
This project is a simple Tic-Tac-Toe game developed in Python. It is a two-player console application where players take turns placing their symbols (X and O) on a 3×3 grid. The game automatically checks for a winner or a draw after every move and displays the final result.

## ✨ Features
- Two-player gameplay
- 3×3 game board
- Input validation for player moves
- Automatic winner detection
- Draw detection
- Easy-to-understand Python code

## 🛠️ Technologies Used
- Python 3
